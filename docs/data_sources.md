# Data sources

| Dataset | URL | Role |
|---------|-----|------|
| Olist Brazilian E-Commerce | https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce | Orders, customers, sellers, products, payments, reviews |
| Olist Marketing Funnel | https://www.kaggle.com/datasets/olistbr/marketing-funnel-olist | MQLs and closed seller deals |

Sources originate from different operational systems and are ingested into
separate schemas (`ecommerce`, `marketing`) before being joined for
acquisition-quality analysis.
